# 九月影博客：网站维护总手册

> 当前网站：`https://ijiuyueying.github.io/`
>
> 本文件是网站长期维护说明。

---

# 一、日常入口

本地只需要记住：

```text
同步博客.bat
    ↓
同步 GitHub 最新内容

网站内容管理.bat
    ↓
管理分类、文章、收藏、图片、视频、音乐、网址

新建博客文章.bat
    ↓
创建文章
```

---

# 二、网站管理菜单

运行：

```text
网站内容管理.bat
```

菜单：

```text
1 文章分类管理
2 收藏模块管理
3 图片收藏管理
4 视频收藏管理
5 歌曲管理
6 网址导航管理
7 自建收藏新增内容
8 网站配置检查
```

---

# 三、新增文章体系

流程：

```text
新增一级分类
        ↓
新增二级分类
        ↓
新增三级分类
        ↓
新建文章
        ↓
同步博客
```

例如：

```text
项目
 └── 银行监管报送
       └── 1104体系
```

# 四、新增收藏模块

例如新增：

```text
软件收藏
书籍收藏
AI工具收藏
```

操作：

```text
网站内容管理.bat

2 收藏模块管理

新增收藏模块
```

系统自动生成：

```text
页面
分类配置
数据文件
```

无需修改代码。


---

# 七、故障处理

## 中文乱码

确认：

- 文件 UTF-8
- 使用新版网站内容管理.bat

## 分类没有显示

运行：

```text
8 网站配置检查
```

## 图片黑屏

检查：

- 文件路径
- 图片是否存在
- GitHub 是否上传
