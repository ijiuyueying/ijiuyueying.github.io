# 九月影博客：网站内容管理菜单速查

> 用途：快速区分 `网站内容管理.bat` 中 1～8 个菜单分别负责什么，以及什么时候使用。

---

## 1. 菜单总览

打开：

```text
网站内容管理.bat
```

会看到：

```text
1. 文章分类管理
2. 收藏模块管理
3. 图片收藏管理
4. 视频收藏管理
5. 歌曲管理
6. 网址导航管理
7. 给自建收藏模块新增内容
8. 检查网站配置
0. 退出
```

---

## 2. 这 8 个菜单有什么区别

| 菜单 | 管什么 | 你什么时候用 |
|---|---|---|
| **1. 文章分类管理** | 管博客文章的一、二、三级分类 | 新增“银行监管 / 制造业 / 电商 / SQL / Python”等文章目录时 |
| **2. 收藏模块管理** | 新建或管理一个全新的收藏大模块 | 以后新增“软件收藏、书籍收藏、游戏收藏、AI工具收藏”等模块时 |
| **3. 图片收藏管理** | 专门管理图片收藏 | 新增图片分类、添加本地图片时 |
| **4. 视频收藏管理** | 专门管理视频收藏 | 添加本地视频、B站视频、外链视频，以及管理视频分类时 |
| **5. 歌曲管理** | 专门管理音乐收藏 | 添加本地音乐、在线歌曲，以及管理歌曲分类时 |
| **6. 网址导航管理** | 专门管理网站链接 | 添加网站、网站说明，以及管理网址分类时 |
| **7. 给自建收藏模块新增内容** | 给第 2 项创建出来的新收藏模块添加具体内容 | 例如已经创建“软件收藏”，然后往里面添加 DBeaver、Typora、PyCharm 等内容 |
| **8. 检查网站配置** | 检查网站配置是否有明显问题 | 发布前检查分类、页面、路径、本地文件、大文件等问题 |

---

## 3. 最容易混淆：2 和 7

可以直接记成：

```text
2 = 建柜子
7 = 往柜子里放东西
```

例如你想新增一个：

```text
软件收藏
```

第一步，先用：

```text
2. 收藏模块管理
→ 新增收藏模块
→ 软件收藏
```

这一步相当于新建一个空的“软件收藏”模块。

然后第二步，用：

```text
7. 给自建收藏模块新增内容
```

往“软件收藏”里面添加：

```text
软件收藏
├─ DBeaver
├─ Typora
├─ PyCharm
└─ MobaXterm
```

所以：

```text
2. 收藏模块管理
= 创建收藏的大类和结构

7. 给自建收藏模块新增内容
= 给已经创建好的收藏大类添加具体条目
```

---

## 4. 3 / 4 / 5 / 6 又是什么

这四个属于已经提前做好的固定内容类型：

```text
3 = 图片柜子
4 = 视频柜子
5 = 音乐柜子
6 = 网址柜子
```

它们和第 2 项不同。

第 2 项主要用于以后新增全新的收藏类型，例如：

```text
软件收藏
书籍收藏
游戏收藏
AI工具收藏
资源收藏
```

而 3 / 4 / 5 / 6 已经是现成的专用模块，因为它们的数据结构和展示方式不同：

- 图片需要图片预览
- 视频需要播放器或视频链接
- 音乐需要音频或正版平台链接
- 网址需要网站链接和说明

---

## 5. 第 1 项为什么和其他项不一样

`1. 文章分类管理` 属于文章体系，不属于收藏体系。

文章结构大致是：

```text
一级文章大类
└─ 二级分类
   └─ 三级分类
      └─ 文章
```

例如：

```text
项目
└─ 银行监管
   ├─ 1104体系
   ├─ G01 / G11 / G12
   └─ 数据治理
```

以后如果增加一个新的文章一级大类，例如：

```text
学习笔记
```

使用：

```text
1. 文章分类管理
```

而不是收藏模块管理。

---

## 6. 第 8 项什么时候用

建议在准备发布博客之前运行一次：

```text
8. 检查网站配置
```

主要用于发现：

- 重复的分类 key
- 文章引用了不存在的分类
- 自建收藏模块缺少页面
- 自建收藏模块缺少数据文件
- 图片 / 视频 / 音乐本地路径不存在
- GitHub 不适合提交的大文件

注意：

配置检查用于发现明显问题，但不能完全替代浏览器和 Windows 本地实际测试。

## 8. 常见使用示例

### 示例 1：增加一个新的文章方向

目标：

```text
学习笔记
└─ 大数据
   └─ Hadoop
```

使用：

```text
1. 文章分类管理
```

之后再使用：

```text
新建博客文章.bat
```

创建文章。

### 示例 2：增加一张新的学习流程图

使用：

```text
3. 图片收藏管理
```

选择分类后添加本地图片。

### 示例 3：增加一个 B 站视频

使用：

```text
4. 视频收藏管理
```

选择“新增 B 站视频”。

### 示例 4：新增一个常用网站

使用：

```text
6. 网址导航管理
```

输入网站名称、网址和说明。

### 示例 5：创建“软件收藏”并添加软件

先：

```text
2. 收藏模块管理
→ 新增收藏模块
→ 软件收藏
```

再：

```text
7. 给自建收藏模块新增内容
→ 软件收藏
→ 添加 DBeaver / Typora / PyCharm 等
```

## 9. 日常推荐流程

GitHub 上有新修改，需要先拉到本地时：

```text
同步博客.bat
```

日常新增内容：

```text
网站内容管理.bat
```

新增文章正文：

```text
新建博客文章.bat
```

完成本地修改后：

```text
发布博客.bat
```

不要在已经完成本地修改后又先执行同步脚本，以免给自己增加冲突处理。
