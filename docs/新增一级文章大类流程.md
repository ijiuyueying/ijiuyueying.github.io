# 新增一级文章大类流程

当前“新建博客文章.bat”已经支持自动扫描 `_menu_defs/*.md`。

只要某个一级模块配置了：

```yaml
article_enabled: true
```

它就会自动出现在“新建博客文章.bat”的一级模块选择列表里，不需要再修改 BAT 或 PowerShell 脚本。

---

## 一、现有“项目”模块

`_menu_defs/project.md` 当前包含：

```yaml
module_key: project
show_top: true
article_enabled: true
top_label: 项目
top_url: /
top_order: 10
```

因此运行“新建博客文章.bat”时，一级模块列表里会出现“项目”。

---

## 二、示例：新增“学习笔记”一级大类

新建文件：

```text
_menu_defs/study.md
```

示例内容：

```yaml
---
module_key: study
show_top: true
article_enabled: true
top_label: 学习笔记
top_url: /study/
top_order: 20
items:
  - key: all
    label: 推荐

  - key: bigdata
    label: 大数据
    children:
      - key: hadoop
        label: Hadoop
      - key: spark
        label: Spark
      - key: flink
        label: Flink

  - key: ai
    label: AI
    children:
      - key: llm
        label: 大模型
      - key: agent
        label: Agent
---
```

注意：如果 `show_top: true`，还需要保证 `top_url` 对应的页面真实存在，例如 `/study/`。菜单配置和文章创建是自动的，但 Jekyll 不会仅凭配置自动创建一个全新的落地页面。

---

## 三、新建文章时会发生什么

同步最新仓库后，双击：

```text
新建博客文章.bat
```

脚本会扫描 `_menu_defs/*.md`，只读取：

```yaml
article_enabled: true
```

的文件。

假设当前有：

```text
项目       article_enabled: true
学习笔记   article_enabled: true
歌曲分类   没有 article_enabled: true
网址导航   没有 article_enabled: true
```

则脚本一级菜单只显示：

```text
1. 项目
2. 学习笔记
```

歌曲和网址不会被当成文章模块。

选择“学习笔记”后，脚本继续读取 `_menu_defs/study.md` 的 `items:`，显示二级、三级分类。

例如：

```text
一级：学习笔记
二级：大数据
三级：Hadoop
```

生成的文章头部会自动包含：

```yaml
---
layout: post
title: 'Hadoop 学习笔记'
date: 2026-08-19 16:30:00 +0800
module: study
categories: [bigdata]
subcategory: hadoop
tags: []
typora-copy-images-to: ../assets/images/${filename}
---
```

其中：

```text
module       一级大类
categories   二级分类
subcategory  三级分类
tags         更细关键词
```

---

## 四、文章详情页也会自动识别

文章详情页读取 `module:` 后，会自动：

- 高亮对应顶部一级模块
- 左侧显示该一级模块自己的分类树
- 面包屑显示对应一级模块名称
- 元信息显示一级、二级、三级中文分类

旧文章如果没有 `module:`，默认按：

```yaml
module: project
```

处理，因此以前文章不用批量修改。

---

## 五、以后新增一级大类的固定步骤

```text
1. 在 _menu_defs/ 新建一个模块 md
2. 设置 module_key
3. 设置 top_label
4. 设置 article_enabled: true
5. 填写 items 二级/三级分类
6. 如果需要顶部入口，设置 show_top: true，并准备 top_url 对应页面
7. 发布/同步
8. 再运行 新建博客文章.bat
9. 新一级模块会自动出现
```

不需要再修改：

```text
新建博客文章.bat
新建博客文章.ps1
_layouts/post.html
_includes/project-side-nav.html
```

除非以后要改变整个分类体系规则。
