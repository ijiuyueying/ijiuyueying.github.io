# 九月影知识库管理系统

专业版管理后台规划。

## 目标

将当前 Jekyll 博客升级为：

- 在线知识库
- 桌面客户端基础
- AI知识库基础

## 架构

```
knowledge-admin
├── frontend      # 管理后台前端
├── backend       # API服务
├── database      # SQLite数据模型
└── docs          # 系统设计文档
```

## 数据来源

当前博客：

- _posts
- _menu_defs
- _data
- assets/images
